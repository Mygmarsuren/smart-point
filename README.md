# Smart Point

Монгол хэлтэй, responsive админ болон хэрэглэгчийн веб прототип. HTML, CSS, JavaScript; dependency installation шаардлагагүй.

## Ажиллуулах

```sh
cd /workspace/smart-point
python -m http.server 3000 --bind 0.0.0.0
```

`index.html` нь үндсэн хуудас. Header-ийн товчоор админ / хэрэглэгчийн хэсэг солигдоно. Энэ нь нэвтрэлт, эрхийн хамгаалалт биш.

## Турших урсгал

1. Админ → Unique код → код үүсгэх → идэвхжүүлэх → кодыг хуулах.
2. Хэрэглэгчийн хэсэг → Кодоор оноо авах → хуулсан кодыг оруулах.
3. Ижил код дахин ашиглагдахгүй. Даалгаврын нэмэлт оноо авах, судалгаанд нэг удаа оролцох.
4. Купон баталгаажуулж авах, оноогоор хүрд эргүүлэх, түүх харах.
5. Админ → Тохиргоо хэсгээс кодын оноо болон хүрдний үнийг өөрчлөх. CSV тайлан, кодын CSV, хэвлэх боломжтой.

Өгөгдөл `localStorage`-ийн `smartpoint-v1` түлхүүрт хадгалагдана. Браузерийн өгөгдлийг устгахад анхны төлөвт орно. Хувийн мэдээлэл, бодит нууц код бүү оруул.
