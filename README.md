# Smart Point Admin

Үйлдвэрлэгч, нийлүүлэгч өөрийн бараа бүтээгдэхүүн, Unique/QR код, оноо олголт, урамшуулал болон эцсийн хэрэглэгчдийн үйл ажиллагааг бүртгэх, тохируулах, удирдах, хянах веб прототип.

## Үндсэн зарчим

Admin дээр тохируулсан мэдээлэл, нөхцөл, дүрэм нь тусдаа эцсийн хэрэглэгчийн веб, апп дээр хэрэгжинэ. Энэ repository зөвхөн Admin вебийн зориулалттай. Хэрэглэгчийн горим солих, код уншуулж оноо авах, хүрд эргүүлэх, купон худалдан авах, судалгаа бөглөх үйлдлүүд энд байхгүй.

## Ажиллуулах

```sh
cd /workspace/smart-point
python -m http.server 3000 --bind 0.0.0.0
```

Эсвэл index.html-ийг браузерт нээнэ. Суулгах dependency байхгүй.

## Боломжууд

- 12 үндсэн цэс, дэлгэгддэг дэд цэсүүд; Тохиргоо Хяналтын самбарын доор.
- Бүтээгдэхүүн харах, текст код бөөнөөр үүсгэх, идэвхжүүлэх, CSV татах, хэвлэх.
- Оноо олгох нөхцөл болон хүрд эргүүлэх үнийн local тохиргоо.
- Хэрэглэгч хайх, жишээ онооны гүйлгээ харах, CSV тайлан.

## Хязгаарлалт

Шинэ дэд хэсгүүдийн зарим нь дэлгэцийн бүтэц төдий. Dashboard нь жишээ статистиктай. Өгөгдөл localStorage-ийн smartpoint-v1 түлхүүрт хадгалагдана; шинэчлэлтээр өмнөх туршилтын өгөгдлийг устгахгүй. Сервер, байгууллага тусгаарлалт, нэвтрэлт, эрхийн баталгаажуулалт, QR хэвлэлийн дүрс, хэрэглэгчийн веб/апп руу нөхцөл түгээх API болон бодит нэвтрүүлэлт хараахан хийгдээгүй.

## Бүтээгдэхүүний шинэ жагсаалт

Зурагтай карт бүр код, нэр, ангилал, үнэ, хэмжих нэгж, савлагаа, олгох оноо харуулна. Нэр/кодоор хайх, ангиллаар шүүх, дэлгэрэнгүй харах болон сонгосон бүтээгдэхүүнд код үүсгэх рүү шилжих боломжтой. Савлагааны SVG зургууд болон үнэ нь жишээ мэдээлэл. Desktop дээр толгойн цэсний товчоор sidebar-ийг нарийсгаж болно; mobile дээр цэсийг нээнэ/хаана.
